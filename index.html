Create the PAT at github.com/settings/personal-access-tokens. Fine-grained PAT: grant this repository Actions → Workflows: read and write and Contents → Read and write. Classic PAT: tick the workflow and repo scopes. The PAT is stored only in this browser's localStorage — never in the URL, the history, or the hash.

Target repository: a public GitHub repo the agent works on. It is cloned fresh on the runner each run; the agent's edits persist to the relay repo's workspace/<session> branch. Leave empty to work inside the relay repo itself.

API key: prefer a repo secret OPENCODE_API_KEY (never leaves GitHub). A key pasted here is sent as a workflow input and is visible on the public Actions run page — only use it if the repo is private or you accept that exposure.

Link a folder on this laptop: its contents are uploaded to the relay repo, the agent works on them on the runner, and the changed files are written back into your folder — with Chrome, Edge or Firefox 135+ (not in private browsing), which expose the File System Access API. Other browsers get upload-only mode: pick the folder to upload, and after each turn download the updated workspace.json. Skips .git, node_modules, dist, build and similar.
